## 🚀 Installation (5 Minutes)

### **Step 1: Upload Theme**
1. Log into your Shopify Admin
2. Go to **Online Store > Themes**
3. Click **"Upload theme"**
4. Select **pellair-oils-theme.zip**
5. Click **"Publish"**

### **Step 2: Configure Metafields** (Required)
Go to **Settings > Custom Data > Products** and add:

| Metafield Name | Namespace.Key | Type |
|----------------|---------------|------|
| Brand | custom.brand | Single line text |
| Accord | custom.accord | Single line text |
| Concentration | custom.concentration | Single line text |
| Top Notes | custom.top_notes | Multi-line text |
| Middle Notes | custom.middle_notes | Multi-line text |
| Base Notes | custom.base_notes | Multi-line text |
| Minimum Order | custom.minimum_order | Integer |

### **Step 3: Start Adding Products**
Add products with these metafields to enable filtering!

## 🎯 Key Workflows

### **Customer Registration Process**
1. Customer visits site → Clicks "Register Your Business"
2. Fills detailed form (personal + business info)
3. Account created with "pending_approval" tag
4. Admin reviews and adds "approved" tag
5. Customer can now checkout with B2B pricing

### **Product Setup**
1. Add product in Shopify Admin
2. Add metafields:
   - Brand: "Guerlain"
   - Accord: "oriental"
   - Concentration: "EDT"
   - Notes: Top, Middle, Base
3. Product appears in filtered collections

### **Brand & Accord Filtering**
- Sidebar filters on collection pages
- Real-time filtering without page reload
- Filter by multiple brands/accords
- Filter by concentration and size
